1  Introduction to Categories

The notion of a category was popularised by Eilenberg and MacLane and is motivated by several examples of essential structures and their associated maps such as groups and group homomorphisms or vector spaces and linear transformations (Eilenberg and MacLane 1945). However, as outlined in the introduction to the paper, one of the main interests in developing this theory lies in studying functors (maps between categories) and maps between functors. We may already be getting a head of ourselves here and so I would like to focus on a structure which many mathematicians become familiar with during their undergraduate degrees, namely the group.

Definition 1.1 (Group) A group is a set \(G\) equipped with a binary operation \(\ast:G\times G\to G\) such that the following axioms are satisfied.

  1. There exists an element \(e\in G\) such that \(e\ast g=g=g\ast e\) for any element \(g\in G\).
  2. For each element \(g\in G\) there exists an element \(g^{-1}\in G\) such that \(g\ast g^{-1}=e=g^{-1}\ast g\).
  3. For any elements \(\alpha,\beta,\gamma\in G\) we have \[\alpha\circ (\beta\circ \gamma)=(\alpha \circ\beta )\circ \gamma\]

Although the group itself is initially an area of interest for the young mathematician, the simple axioms giving rise to properties such as uniqueness of identities and inverses, one realises rather swiftly that the beauty of the theory of groups lie in the study of the relation between groups. This work is done by group homomorphisms, the mappings associated to group theory.

Definition 1.2 (Group homomorphism) Let \(G\) and \(H\) be groups, then we call a map \(\phi: G\to H\) a group homomorphism if for any \(g,h\in G\) we have \[\phi(g\ast_G h)= \phi(g)\ast_H\phi (h)\]

Group homomorphisms are verily stronger than a simple map on the underlying sets, as they ensure that the group operation is respected. It carries the strucure of the domain in a nice manner, mapping the domain’s identity to the identity of the codomain, and similarly bringing inverses to inverses in the obvious manner. Naturally the simplest group homomorphism we can create for any group \(G\) is probably the identity which maps a group \(G\) to itself.

Example 1.1 (The identity homomorphism) Let \(G\) be a group and consider tha mapping \(\id_G :G\to G\) which is defined by \(g\mapsto g\). This clearly forms a group homomorphism as both domain and codomain posess the same group operation.

Every structure should give rise to identity maps, the example above gives each group an identity homomorphism, for vector spaces we have the identity matrices, for topological spaces we have the identity map. They all posses the same intuitive quality, identities change nothing, the structure which arises from the image of the identity is the same as the structure of the domain on which it acts. This notion becomes more tangible when we discuss about the composition of maps. Note that a group homomorphism \(\phi\) has a source group \(G\) and a target group \(H\) called the domain and codomain respectively, and these groups encode which other homomorphisms can be used in composition with \(\phi\). We denote the domain of a group homomorphism \(\phi\) by \(\dom\phi\) and the codomain by \(\cod\phi\). Let \(\Mor_{\Grp}\) denote the class of all group homomorphism, and let \(\Mor_{\Grp} \times_{\Grp}\Mor_{\Grp}\) denote the set \[\{(\psi, \phi)\in \Mor_{\Grp} \times\Mor_{\Grp}\,\vert\, \cod\phi=\dom\psi \}\] Then we define the composition operation on the class of group homomorphisms.

Definition 1.3 (Composition of group homomorphism) The class function \(\circ : \Mor_{\Grp} \times_{\Grp}\Mor_{\Grp}\to \Mor_{\Grp}\) defined by \((\psi,\phi)\mapsto [x\mapsto \psi (\phi(x))]\) is called the composition map of group homomorphisms. We denote \(\circ (\psi, \phi)\) by \(\psi\circ\phi\).

I agree with the sentient that the tedium here is excesssive and is not necessary in forming an understanding of group theory, however, I believe this view of composition will aid in understanding the generalisation which we present in category theory. The mappings in category theory (which will be called morphisms) are in general far more abstract. We might not be able to speak of images of single points in a domain, nor would we be able to speak of if a point is a member of the kernel or not. Theses abstracted properties are instead presented by the structures of morphisms in relation to each other and through composition. That being said, we will examine how the composition of group homomorphisms work by doing it element wise.

Example 1.2 (Composition with identity homomorphism) Let \(\phi:G\to H\) be a group homomorphism, and consider the following compositions with the identity \(\id_G\) and the identity \(\id_H\) \[\phi\circ\id_G(g)=\phi(\id_G(g))=\phi(g)\] and similarly we have that \[\id_H\circ \phi(g)=\id_G(\phi(g))=\phi(g)\]

The example above demonstrates that if a group homomorphism \(\phi\) has domain \(G\) then \(\phi=\phi\circ \id_G\) and if it has codomain \(H\) then \(\phi = \id_H\circ \phi\). We can always reduce any well defined composition with an identity, this will be a fundamental concept in the theory of categories. This is particularly useful when we compose a map with its inverse, which may of course not always exist. We usually learn that a group isomorphism is a homomorphism which is bijective. However, when working with categories we want to distance ourselves from thinking about the images of elements and think of the possible interactions of the map in question with other maps with which it can be composed. Therefore, we think of right and left inverses, and a map admits an inverse if it admits both a right and a left inverse.

Definition 1.4 (Inverse homomorphism) Let \(\phi:G\to H\) be a group homomorphism. A group homomorphism \(\psi: H\to G\) is called a right inverse of \(\phi\) if \(\phi\circ \psi=\id_H\) and it is called a left inverse of \(\phi\) if \(\phi\circ\psi=\id_G\). Furthermore, \(\psi\) is called an inverse of \(\phi\) if it is both a right and left inverse of \(\phi\).

Usually we are introduced to group isomorphisms as bijective group homomorphisms, however here we will adopt the view which will give rise to the definition of the general isomorphism in the theory of categories. Instead of considering injectivity and surjectivity of a group isomorphism we will consider inverses.

Proposition 1.1 A group homomorphism \(\phi : G\to H\) admits an inverse \(\psi: H\to G\) if and only if it is an isomorphism.

Proof. Suppose that \(\psi\) is an inverse of \(\phi\). Let \(h\in H\), we will show that there exists an element \(g\in G\) such that \(\phi(g)=h\). Note that \[h=\id_H(h)=\phi\circ\psi (h)\] and as \(\psi(h)\in G\) we have that \(\phi\) is surjective. Consider now two elements \(g_1, g_2\in G\) such that \(\phi(g_1)=\phi(g_2)\), we will now show that we must have \(g_1=g_2\). We have \[g_1=\id_G (g_1)=\psi\circ\phi(g_1)=\psi(\phi(g_1))=\psi(\phi(g_2))=\psi\circ\phi(g_2)=\id_G(g_2)=g_2\] and so it follows that \(\phi\) is injective.

Conversely, suppose that \(\phi\) is an isomorphism, which is that it is both surjective and injective. Let us consider the map \(\psi :H\to G\) defined by sending \(h\in H\) to the unique element in its preimage under \(\phi\), uniqueness follows from injectivity and existence follows from surjectivity. Then \(\phi\circ \psi(h)=h\) and so \(\phi\circ \psi=\id_H\), further, \(\psi\circ \phi(g)=g\) and so \(\psi\circ \phi=\id_G\). Now \(\psi\) is an inverse of \(\phi\).

This will likely not have been anything new to the reader, however if you have not been exposed to category theory before then this shift in perspective towards examining properties of maps by how they compose with others is going to aid in abstracting the essence of what gives structure to all agebraic structures. More generally than the result above we have that a group homomorphism is injective if and only if it admits a left inverse and it is surjective if and only if it admits a right inverse.

Finally, I would like to bring our attention to subgroups. Recall that a subset \(H\) of a group \(G\) is called a subgroup if \(H\) forms a group with respect to the group operation \(\ast_G\). Equivalently, a nonempty subset \(H\) is a subgroup if it is closed under \(\ast_G\) and inverses. Generally, algebraic structures have underlying sets and so a substructure \(B\) of an algebraic structure \(A\) is just a subset \(B\) such that when endowed with the same operations as \(A\) it satisfies the axioms of being the type of structure in question. This is unfortunaetly not quite as easy in category theory in its fullest generality, the underlying objects which form a category are not sets with structure, they may be far more abstract and do not contain elements. Subobjects and quotients are not as obvious in the general category as it for groups and vector spaces. In practice one often works with categories in which the objects have underlying sets and maps have kernels, images, cokernels, et cetera. We will explore when we can treat categories as if they have elements in each object later. ## Our first category

Definition 1.5 (Category) A category consists of a pair of classes \((\Ob, \Mor)\), a pair of class functions \(\dom, \cod:\Mor\to \Ob\) and a class function \[\circ: \Mor\times_{\Ob}\Mor\to \Mor\] where \[\Mor\times_{\Ob}\Mor:=\{(\psi,\phi)\in \Mor\times \Mor\,\vert\,\dom \psi=\cod \phi\}\] which satisfy the following axioms. Note that here we write \(\psi\circ \phi\) instead of \(\circ (\psi, \phi)\).

  1. For any two elements \((\psi,\phi)\in \Mor\times_{\Ob} \Mor\) we have \(\dom (\psi\circ\phi)=\dom \phi\) and \(\cod (\psi\circ\phi)=\cod \psi\).
  2. For elements \(\phi, \psi, \rho\in \Mor\) such that \(\psi\circ\phi\) and \(\rho\circ \psi\) are well defined we have that \[\rho\circ (\psi\circ\phi)=(\rho\circ\psi)\circ \phi\]
  3. For each \(X\in \Ob\) there exists an element \(\id_X\in \Mor\) with \(\dom \id_X = \cod \id_X=X\) such that we have \[\id_X\circ \phi= \phi\] for all \(\phi\in\Mor\) with \(\cod \phi = X\), and \[\psi\circ \id_X=\psi\] for all \(\psi\in\Mor\) with \(\dom \psi = X\).
